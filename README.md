# PC-6001 ハイパーグラフィックエディタ 簡易版

ブラウザで動く PC-6001 用ドット絵エディタ（**非公式ファンツール**）です。

## 使い方

1. 下の URL を開く  
2. 描画して PNG / p6json で保存

**公開URL（GitHub Pages）:**

```text
https://kshiroh.github.io/hyper-graphic-editor-light/
```

本体ファイルが `simple.html` の場合は、次でも開けます。

```text
https://kshiroh.github.io/hyper-graphic-editor-light/simple.html
```

## 主な機能

- SCREEN 1 / 2 / 3 / 4 / mkII 15色
- ペン・消しゴム・塗りつぶし・市松塗り・スポイト
- 走査線・にじみ（TV風表示）
- ストレッチ表示
- PNG（倍率指定）/ ASM / p6json の保存・読込
